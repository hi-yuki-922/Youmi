# Youmi 迭代三：浮层共存、斜杠命令、应用图标、monaco 与汇率换算

Status: ready-for-agent

## Problem Statement

迭代二收口后的实机使用与能力缺口：

- 命令面板与剪贴板两个浮层**无法同时打开**——呼出一个就把另一个藏掉。根因不是显式互斥代码，而是每个浮层窗口注册的"失焦即隐"事件把焦点转移到兄弟浮层也当成"用户离开了"。
- 想翻译一段文字时要在面板里打 `/t` 之外的完整路径：先呼面板搜工具、再等页面就绪、再点输入框——缺一条**带参数直达**的通道。
- 命令面板能启动应用但条目一律是通用窗口图标，几百个应用里**靠名字认图标**太慢。
- JSON 工具输入输出是原生 textarea，无语法高亮、无错误标红，长 JSON 编辑体验差。
- 缺**汇率换算**工具：查一个金额兑多币种要去网页。

## Solution

三项增强 + 两项新能力：

1. **浮层共存**：焦点在 youmi 浮层之间转移时不再互相隐藏，点击浮层以外区域才全部隐藏；三个浮层（命令面板、剪贴板、划词翻译）统一适用。
2. **斜杠命令**：通用注册表机制（`/命令名 参数`），`/t <文本>` 直达主窗口翻译页并自动触发翻译。
3. **应用图标**：命令面板应用条目显示真实图标，按需提取 + 磁盘缓存，失败回退现有图标。
4. **monaco editor**：JSON 工具输入/输出替换为 monaco，本地打包、主题跟随系统明暗。
5. **汇率换算**：新工具页——源币种 + 金额，下方目标币种行列表展示换算结果。

## User Stories

1. As a user, I want 剪贴板浮层开着时呼出命令面板两者同屏可见, so that 边查历史边搜工具不丢上下文。
2. As a user, I want 面板里输入 `/t 你好世界` 回车直接得到翻译, so that 翻译一步直达。
3. As a user, I want 面板应用条目显示应用自己的图标, so that 视觉定位比读名字快。
4. As a user, I want JSON 长文本有语法高亮与错误标红, so that 定位格式问题不靠数行。
5. As a user, I want 输入金额后同屏看到多个币种的换算结果, so that 出行/购物比价一眼完成。

## Implementation Decisions

- **共存机制**：不改"失焦即隐"本身——它是点击外部隐藏的实现载体。在失焦处理处增加判断：失焦是焦点转移到任一 youmi 浮层所致时不隐藏。机制按窗口类别统一，不做按窗口名的特判。pinned 固定豁免、Esc 关闭、点击外部隐藏语义全部不变。
- **斜杠命令**：注册表与 `TOOLS` 常量数组同构（name、描述、用法提示、handler），输入 `/` 列出全部命令、按命令名前缀过滤、未知命令提示；`/` 前缀模式下结果列表只含斜杠命令，不混工具/应用/算式搜索。参数以第一个空格分隔（`/t你好` 不算命令）。`/t <文本>` → 收起面板、主窗口前置、切翻译页、填充并自动触发翻译；裸 `/t` 仅打开翻译页；缺 API key 走翻译页既有引导态；翻译流式中再触发即停止旧会话。通道为扩展既有 `open-tool` 事件 payload（tool id + 可选文本）。
- **应用图标**：Rust 侧 `SHGetFileInfoW` 提取（`.lnk` 自动解析目标 exe 图标）转 PNG，新增按路径取图标的 command；前端按需拉取 + 磁盘缓存（app data 目录，key = lnk 路径 + mtime），加载期间先显示回退图标异步替换，提取失败回退现有 lucide 图标。
- **monaco**：输入框与输出框都替换（输出只读），**本地打包**（桌面离线场景禁用 CDN loader，workers 一并打包）；主题监听 `prefers-color-scheme` 在暗/亮两套主题间切换（应用无应用内主题开关，跟随系统）；格式化/压缩/校验/转义/去转义按钮组与缩进选择保留，monaco 自带 JSON 校验标红与既有行列错误提示叠加；输入/输出持久化沿用 `usePersistedToolState`。
- **汇率换算**：形态为一页换算表——顶部源币种下拉 + 金额输入，下方目标币种行列表（增删行、行选择持久化，首次默认 USD/EUR/JPY 三行），换方向即切换源币种。数据源 open.er-api.com（免费无 key，160+ 币种，每日更新）；币种下拉可搜索，内置 ISO 4217 中文名映射；打开页面时缓存超 6 小时静默刷新 + 手动刷新按钮 + 展示数据更新时间；离线用最后缓存并标注。

## 迭代顺序

01 浮层共存 → 02 斜杠命令 → 03 应用图标 → 04 monaco → 05 汇率换算（顺序即优先级；无相互 blocking，后项不 gate 前项验收）。
