# Youmi 迭代二：缺陷修复、工作台打磨与翻译工具

Status: ready-for-agent

## Problem Statement

MVP 实机使用暴露的缺陷与摩擦：

- 剪贴板浮层的**回帖**在目标为主窗口时静默失效——JSON 工具、编码转换、文本 diff 的输入框收不到内容（回帖目标校验把自家窗口全部排除）。
- 文本 diff 输入较长内容后 diff 视图无法滚动，长对比不可用。
- 剪贴板浮层经 Alt+V 呼出后 Alt 的按下状态残留：此时按 ↓ 会打开系统窗口菜单，需再按一次 Alt 并松开才恢复正常。
- 日常摩擦：工具页切换路由后输入全部丢失；输入框没有清空按钮；SVG 工具拿到 data URI 后还要手工拼 iconify/scss 片段、没有预览；设置页高度不足时出现原生滚动条；快捷键用纯文本展示、没有作用域说明；录制快捷键时无法用鼠标取消。
- 想翻译一段自己写的文字时只有划词翻译入口（先选中再呼出），缺一个能直接打字的翻译页。

## Solution

三个缺陷按根因修复；十个体验优化落位（输入清空、工具页状态持久化、ScrollArea、Kbd 快捷键展示体系与作用域标注、密码本"永不锁定"、剪贴板浮层 Alt+1~5 快速回帖、SVG 预览与 scss 模板）；新增主窗口"翻译"**工作台工具**：中英互译、Ctrl+⏎ 触发、流式输出，复用划词翻译的 DeepSeek 基础设施。

## User Stories

### 缺陷修复

1. As a user, I want 焦点停在主窗口工具输入框时呼出剪贴板浮层回帖, so that 条目内容直接进入 JSON 工具/编码转换/文本 diff 的输入框。
2. As a user, I want 文本 diff 在内容超长时也能垂直滚动, so that 长文本对比不截断。
3. As a user, I want 用 Alt+V 或命令面板快捷键呼出浮层后立即按 ↓, so that 移动选择而不是误开系统窗口菜单。

### 工作台打磨

4. As a user, I want SVG 编码工具里直接预览渲染输入的 SVG, so that 编码前确认图标长相。
5. As a user, I want 输入 iconName 后得到 `--svg: url(...)` + `@include icon;` 的 scss 片段并一键复制, so that 直接贴进 iconify 风格的项目样式。
6. As a user, I want JSON 工具、编码转换三个子工具与文本 diff 的每个输入框都能一键清空, so that 换内容不用手动全选删除。
7. As a user, I want 工具页状态（输入/输出/子 tab/缩进）在切换路由和重启应用后都保留, so that 切走查资料再回来不丢现场。
8. As a user, I want 密码本锁定超时可设为 0 = 永不自动锁定, so that 长会话不被打断、需要时手动点锁定。
9. As a user, I want 主窗口页面滚动用统一的 ScrollArea 样式, so that 不出现突兀的原生滚动条。
10. As a user, I want 快捷键与操作提示用 Kbd 符号展示（⌃⇧⌘⊞⏎⎋↑↓←→）, so that 一眼读出组合键。
11. As a user, I want 修改快捷键变成图标按钮、录制中隐藏且点击任意位置即取消, so that 录制交互干净可控。
12. As a user, I want 剪贴板浮层内按 Alt+1~5 直接回帖当前可见列表的前五条, so that 免键盘导航直达。
13. As a user, I want 设置页快捷键按作用域分组并标注（全局 / 剪贴板）, so that 知道每个组合键在哪里生效。
14. As a user, I want 命令面板与剪贴板浮层的"回车"提示统一为 Kbd ⏎, so that 提示风格一致。

### 翻译工作台工具

15. As a user, I want 主窗口侧边栏出现"翻译"页且命令面板可搜到, so that 手动输入文本翻译有落脚点。
16. As a user, I want 中英双向翻译、双下拉加交换按钮、默认英→中, so that 对齐 DeepL 的方向选择习惯。
17. As a user, I want Ctrl+⏎ 或点"翻译"按钮触发翻译、译文流式呈现, so that 控制调用时机且反馈即时。
18. As a user, I want 译文一键复制, so that 译完即用。
19. As a user, I want API key 未配置时页内提示并引导到设置, so that 不用到处找配置入口。
20. As a user, I want 翻译页与划词翻译共享模型名与 API key 设置, so that 一处配置两处可用。

## Implementation Decisions

### 缺陷修复

- **回帖支持主窗口目标**：目标捕获不再无条件排除主窗口——捕获时前台是主窗口则记录为回帖目标（浮层窗口仍排除）；回帖编排对主窗口目标先唤起（还原最小化、显示、置前台）再走既有「自家写入通道写剪贴板 → 浮层隐藏 → 焦点等待与前台校验 → 模拟 Ctrl+V」流程。原剪贴板恢复（延迟 + 序号守卫）语义不变；`copied-only` 降级含义不变（仅异常路径）。焦点不在文本输入处时与回帖到其他应用一致：Ctrl+V 静默无效，不做降级提示。
- **diff 滚动**：diff 视图的滚动属于 `@pierre/diffs` 内部 scroller——wrap 模式下库禁用了部分滚动行为，叠加应用侧 overflow-hidden 高度约束导致不可滚。修复以"长内容可垂直滚动"为验收行为：应用侧只保留高度约束、不接管滚动；若需覆写优先用库提供的 overflow 覆写变量，不 fork。
- **残留修饰键清理**：浮层呼出路径（剪贴板、命令面板）在窗口 show 后补发残留修饰键 keyup；清理原语与回帖/划词取词路径共用同一实现（查询异步键态后补 keyup，不回按）。

### 工作台打磨

- **Kbd 体系**：新增 Kbd 展示组件与组合键格式化符号映射：Ctrl→⌃、Shift→⇧、Alt→⌘、Win→⊞、Enter→⏎、Esc→⎋、方向键→↑↓←→。应用范围：设置页快捷键列表、命令面板行提示（回车打开/复制/启动 → ⏎）与底部提示、剪贴板浮层底部提示、翻译页触发提示。Alt 与 Win 必须可区分（⌘ vs ⊞），不得都渲染为 ⌘。
- **快捷键作用域**：两类——`全局`（系统级注册、任意应用生效）与`剪贴板`（浮层窗口内生效）。设置页按作用域分组；剪贴板组为只读条目（不走全局快捷键注册、不参与改键）。
- **录制交互**：修改按钮改为 lucide 图标按钮；开始录制后按钮隐藏、不提供取消按钮；前端监听 mousedown——录制期间鼠标点击任意位置即取消录制（调用既有取消命令）；Esc 保留为取消手段；10 秒录制超时行为不变。
- **剪贴板 Alt+1~5**：浮层内前端键盘监听实现（非全局注册、不占全局改键表）；作用于当前可见（含搜索过滤后）列表的前五条，行为等同双击回帖；列表前五行内显示对应数字角标；焦点在搜索框时同样生效。
- **状态持久化**：JSON 工具、编码转换（含子 tab 与三个子工具）、文本 diff 的全部状态（输入、输出、错误态、视图/缩进选择）经 localStorage 持久化，按工具划分存储键，挂载时恢复；不经 tauri store（工具内容无敏感要求）。
- **清空按钮**：复用 LabeledTextarea 的 label 行动作位放置清空按钮，直接清空不做确认；转换类工具清空输入时联动清空输出与错误态。
- **ScrollArea**：`/_main` 布局的共享内容卡片容器替换为 shadcn ScrollArea（radix），主窗口所有工具页滚动条样式统一，不使用原生滚动条样式；避免双重滚动。
- **密码本锁定超时 0=永不**：前端钳制放宽为 0..1440 分钟；Rust 端 0 特判——autolock 哨兵线程不排期、命令路径过期检查恒不过期；设置 UI 数字输入支持 0 并显示"永不"说明。手动锁定按钮行为不变。
- **SVG 工具增强**：预览卡片直接内联渲染输入的 SVG；scss 模板输出 = `.{iconName} { @include icon; --svg: url(<现有 data URI 输出>); }`，iconName 为独立输入框（默认占位 `icon`），变更实时重生成，一键复制。data URI 复用现有编码实现，无新增编码逻辑；输入非法 SVG 时预览呈错误态不白屏。

### 翻译工作台工具

- 新工作台工具"翻译"注册进工具注册表（侧边栏与命令面板共用同一数据源），路由 `/translate`。
- 方向选择：中/英双下拉 + 交换按钮（DeepL 式布局），默认英→中；不做自动检测。
- 触发：输入区 Ctrl+⏎（Kbd 提示）或"翻译"按钮；翻译中再次触发即中止上一次（沿用 AbortController 语义）。
- 流式渲染与 DeepSeek 调用复用划词翻译基础设施：模型名（translate.model 设置）与 API key 凭据共享；prompt 层把方向规则泛化为"目标语言"参数，划词翻译既有三方向（自动→中文/中→英/英→中）继续工作，行为不得回归。
- API key 未配置：页内呈提示态并引导跳转设置页对应分区，不弹全局错误。
- 不做翻译历史。

## Testing Decisions

沿用 MVP 两层既有 seams，不新增 seam：

1. **Rust 模块公共接口**（cargo test）：回帖编排新增主窗口目标用例——捕获记录主窗口、浮层仍排除、编排对主窗口先唤起后粘贴、异常路径仍降级 copied-only（prior art：回帖编排 fake 平台注入 14 例）；锁定超时 0 语义——autolock 永不触发、解锁会话不过期（prior art：vault 锁定行为测试）。
2. **前端工具核心纯函数层**（vitest）：组合键符号格式化映射（含 `super+alt+space` → ⊞⌘Space 一类多修饰组合）；SVG scss 模板生成（iconName 注入与特殊字符处理）；工具页持久化的序列化/恢复 roundtrip（prior art：`src/tools/*` 纯函数测试）。
3. **实机手动验收**：UI 交互（录制取消、diff 滚动、ScrollArea 视觉、Kbd 呈现、Alt+1~5、翻译页端到端）与涉键击注入的修复（残留 Alt 清理、回帖主窗口）不写自动化 UI 测试，按 MVP 惯例以 verify 脚本 + 实机验收清单收口（prior art：`.scratch/youmi-mvp/verify/`、MVP 验收票）。

- 好测试只断言外部行为（输入→输出、可见状态变化），不断言实现细节。

## Out of Scope

- 翻译：中英以外语言、自动检测源语言、翻译历史、word/excel/pdf/网页/图片文件翻译、划词翻译浮层改造
- 剪贴板：Alt+1~5 之外的浮层内快捷键扩展
- 快捷键：剪贴板作用域组合键的用户改键（本轮只读展示）
- 设置页之外的逐页 ScrollArea 定制
- macOS/Linux 实现

## Further Notes

- 术语：本 spec 用域词**回帖**（需求原述"回写"）；域词表见 CONTEXT.md。
- Alt+1~5 在焦点位于搜索框时同样生效（Alt 组合不产生字符输入，不影响打字）。
- 翻译页的 prompt 泛化是一次共享核心重构：划词翻译的既有行为（三方向 + 流式 + 失焦隐藏）是回归红线。
- 批次顺序：缺陷修复 → 工作台打磨 → 翻译工具；实机验收票最后收口。
