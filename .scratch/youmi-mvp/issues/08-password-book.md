## Comments

### 实现记录（2026-10-14）

**Rust（`src-tauri/src/vault/`，新模块）：**

- `crypto.rs`：Argon2id（库默认参数，OWASP 推荐）派生 256 位密钥 + AES-256-GCM；密文 blob 格式 `nonce(12B) ‖ ciphertext+tag`，nonce/salt 每次随机。错误主密码靠 GCM 认证标签识别。
- `repository.rs`：`vault_meta`（单行：salt + 校验器）与 `vault_entries`（`data` = 整条载荷 JSON 的密文）两张表，db.rs 追加 V2 迁移；repo 层只搬字节不懂密钥。
- `mod.rs`：解锁会话状态机——派生密钥 `Zeroizing` 包裹、落锁即清零；`ensure_unlocked` 在每次条目操作前做超时检查并刷新活跃时间；校验器（加密的已知明文）解密成功即主密码正确。复制字段经剪贴板引擎自家写入通道写出，30 秒后带剪贴板序号守卫清除（延迟窗口内用户复制了新内容则放弃，保护新内容——与回帖恢复同模式）。
- `lib.rs`：`vault_*` 10 个 command；1 秒 tick 的自动锁定哨兵线程，到期落锁时向主窗口发 `vault-locked` 事件驱动 UI 切回解锁界面（命令路径另有到期检查兜底）。
- `db.rs`：`db::open` 加 5 秒 busy_timeout——剪贴板与密码本两个连接共用 `youmi.db`，SQLite 默认无 busy handler，写冲突会直接报 BUSY。

**前端：**

- `lib/vault.ts`：command 封装 + 锁定超时设置（分钟，存 settings.json，默认 5）+ `onVaultLocked` 事件订阅。
- `password-book.tsx`：三态页面（设置主密码 → 解锁 → 列表）；搜索框走 `vault_query`（Rust 侧按标题/用户名大小写不敏感过滤，密文不入 webview 之外的存储）；条目模态表单（新建/编辑、密码显隐）；删除用与剪贴板浮层清空一致的两段式确认；解锁/落锁/超时锁定均失效 `vault-status` 查询切界面。
- `settings.tsx`：密码本区新增「锁定超时」（分钟输入，失焦/回车提交，后端 clamp 回显）；`_main.tsx` 启动时应用持久化超时（同剪贴板容量模式）。

**测试：** cargo 105 全过（含新增 21 个：crypto roundtrip/错误密码/篡改/nonce 唯一性、repo CRUD/持久化/二次初始化拒绝、会话 setup/unlock/锁定循环/超时落锁/锁定拒操作、复制不入史/序号守卫清除/空字段/无引擎降级、`database_file_stores_no_plaintext` 直查落盘字节断言无任何明文且重开可解）；vitest 84 全过；tsc / oxlint / clippy / cargo fmt 干净。

### 实机冒烟路径（人工验收）

1. 打开密码本页 → 设置主密码（<8 位 / 两次不一致应有行内报错）→ 进入空列表。
2. 新建条目（标题必填），列表出现；搜索标题/用户名关键词过滤正确。
3. 复制密码 → 到剪贴板浮层确认历史未新增 → 粘贴可用 → 30 秒后剪贴板被清空；复制后立即手动复制其他内容，30 秒后新内容不被清掉。
4. 点「锁定」→ 回解锁界面；错误主密码提示「主密码错误」；正确密码解锁后条目仍在。
5. 设置页改锁定超时为 1 分钟 → 解锁后静置 1 分钟 → 页面自动切回解锁界面。
6. 重启应用 → 直接处于锁定态，解锁后条目完整；用 SQLite 工具打开 `youmi.db` 确认 `vault_entries.data` 无明文。
