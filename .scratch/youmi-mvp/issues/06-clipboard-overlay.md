# 06 — 剪贴板浮层 v1

**What to build:** 第一个全局工具浮层：按 `Win+V` 呼出无边框、置顶的剪贴板管理浮层——列表浏览剪贴板历史、关键词搜索、文本/图片分类查看、删除单条；失焦自动隐藏、再次呼起瞬时；设置页新增历史容量项与"请先关闭系统剪贴板历史"引导。浮层窗口模式（decorations:false / alwaysOnTop / 失焦 hide 而非销毁 / 定位到鼠标所在显示器）在此确立，供 09、11 复用。快捷键经 global-shortcut 插件注册。

**Blocked by:** 04 — 托盘常驻 + 单实例 + 设置页雏形；05 — 剪贴板捕获与存储引擎

**Status:** ready-for-agent

- [ ] Win+V 呼出/隐藏浮层，浮层出现在鼠标所在显示器
- [ ] 列表展示文本与图片条目，可搜索、可按类型过滤、可删除单条
- [ ] 失焦即隐，再次呼起瞬时（hide 而非销毁窗口）
- [ ] 设置页可修改历史容量并生效
- [ ] 设置页含"在 Windows 设置中关闭系统剪贴板历史"的引导提示
