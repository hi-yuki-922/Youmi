# 01 — 回帖支持主窗口目标

**What to build:** 焦点在主窗口任意工具输入框时呼出剪贴板浮层，回帖把条目内容粘贴进该输入框光标处——JSON 工具、编码转换、文本 diff 的输入框不再收不到回帖。目标捕获放开主窗口限制（浮层窗口仍排除）；回帖编排对主窗口目标先唤起（还原最小化、显示、置前台）再走既有「自家写入通道写剪贴板 → 浮层隐藏 → 焦点等待与前台校验 → 模拟 Ctrl+V」流程；原剪贴板恢复与 copied-only 降级语义不变。

**Blocked by:** 无——可立即开始

**Status:** ready-for-agent

- [ ] 焦点在 JSON 工具输入框 → Alt+V → 双击条目：内容粘贴进该输入框光标处
- [ ] 编码转换与文本 diff 的输入框同样可回帖
- [ ] 焦点在主窗口非输入区时回帖：无粘贴、无报错，条目已复制可手动 Ctrl+V
- [ ] 回帖后用户原剪贴板内容恢复、剪贴板历史不变
- [ ] 前台是浮层窗口时捕获行为不变（排除浮层/清过期目标）
- [ ] cargo test 覆盖主窗口目标用例（捕获记录主窗口、浮层仍排除、异常路径降级）；实机验证脚本留档 verify/
