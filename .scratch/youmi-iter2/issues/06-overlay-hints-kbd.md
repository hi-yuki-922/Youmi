# 06 — 浮层提示 Kbd 化

**What to build:** 命令面板活动行提示（回车打开/复制/启动）与底部提示、剪贴板浮层底部提示统一改为 Kbd 呈现（⏎ ↑↓ ⎋），与全局快捷键展示体系一致。

**Blocked by:** 04 — Kbd 组件与组合键符号格式化

**Status:** done（2026-10-16 实机验收通过）

- [x] 命令面板活动行提示 ⏎ Kbd 化（打开/复制/启动三类）
- [x] 命令面板底部提示 Kbd 化
- [x] 剪贴板浮层底部提示 Kbd 化
- [x] 提示语义与布局不变（仅呈现方式变化）

## Comments

### 2026-10-16 — 实现说明

- 命令面板（`palette.tsx`）：活动行提示由"回车打开/复制/启动"改为 `⏎` Kbd + 动词；底部提示由纯文本改为 `↑` `↓` 选择 · `⏎` 打开工具、启动应用或复制结果 · `⎋` 关闭（flex + gap，仍单行）。
- 剪贴板浮层（`clipboard.tsx`）：底部提示改为 `↑` `↓` 选择 · `⏎` 或双击回帖到之前的窗口。
- 文案语义逐词保留，仅"回车"词面替换为 ⏎ Kbd；行 aria-label 等读屏文本不受影响。

### 2026-10-16 — 实机验证记录（CDP 驱动 dev 应用，截图 iter2-palette-kbd.png / iter2-clipboard-kbd.png）

- 面板：底部 Kbd 序列 `[⏎,↑,↓,⏎,⎋]`、文本"↑↓选择·⏎打开工具、启动应用或复制结果·⎋关闭"；活动行"编码转换 ⏎ 打开"。
- 剪贴板浮层：底部 Kbd `[↑,↓,⏎]`、文本"↑↓选择·⏎或双击回帖到之前的窗口"。
- 提示仍各占底部一行、边框/内边距/字号不变。
