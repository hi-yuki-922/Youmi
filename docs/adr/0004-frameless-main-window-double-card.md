# 主窗口去原生边框自绘标题栏；内容区采用双卡片嵌套布局

原生标题栏与应用内界面风格割裂。决策：主窗口 `decorations: false`，自绘标题栏——可拖拽区（双击最大化）+ 最小化/最大化/关闭；关闭维持"隐藏到托盘"语义，不退出进程。主窗口布局采用双卡片嵌套：窗口背景层为较深的灰，侧边导航置于背景层，主内容区为浅一档的卡片叠于其上；深色模式下两层各自取深色值（背景更深、卡片略浅）。浮层窗口不受影响（本就无边框、无标题栏）。窗口控制按钮完全自绘以贴合 token 体系。

## Considered Options

- 保留原生边框 —— 被拒：与应用内视觉割裂
- window-controls-overlay 半原生方案（原生控制按钮叠加在自绘标题栏上）—— 被拒：原生按钮样式脱离 token 体系，与 UI 一致的目标冲突；其保留 Snap Layouts 的收益在 v1 不值

## Consequences

- 拖拽、双击最大化、最小化/最大化/关闭的行为由自绘实现负责，需逐一覆盖
- 原生 Snap Layouts（悬停最大化的分屏面板）在 v1 失效，日后评估专门方案
- 双卡片的两层 surface 进入 token（背景层/卡片层），成为全应用的层次语言，浮层与新窗口复用
